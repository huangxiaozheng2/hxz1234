# 淮安印记 · 运河之都文旅闯关游戏

一个手机网页闯关游戏：游客扫二维码打开，不用下载，也不用登录。在闯关地图上依次挑战淮安四个站点，每站先听故事，再玩一个跟这一站有关的小游戏，过关后盖一枚印章。集齐四枚印章后进入限时答题大挑战，最后根据成绩评出称号，并生成可以发朋友圈的分享海报。

## 玩法

| 站点 | 小游戏 | 玩法 | 评星 |
|---|---|---|---|
| 周恩来故里 | 少年志向 | 把周恩来一生的六件大事按时间先后排好 | 看失误次数 |
| 河下古镇 | 金箍棒打妖怪 | 30 秒打地鼠：打妖怪加分，金色妖怪加 3 分，打到唐僧扣 3 分 | 看得分 |
| 清江浦 · 大运河 | 漕船运粮 | 竖屏跑酷：左右换航道，躲开礁石和浮木，收集粮袋，开到清江浦 | 安全到站得 1 星，再按粮袋数加星 |
| 淮扬美食 | 吃汤包 | 按「轻轻提、慢慢移、先开窗、后喝汤」四步操作：按住控制力度、慢慢拖动、选对动作、吸一口吹一吹 | 看失误次数 |

- **印记大挑战**：从 17 道题的题库里随机抽 6 题，每题限时 15 秒。答得越快分越高，连续答对有连击加成。
- **称号**：按「印章星数 60% + 答题正确率 40%」计算，分为「初识淮安」「淮安行家」「文旅达人」三档，各有一枚徽章。
- **分享海报**：海报上有昵称、称号、四枚印章、总分和二维码。在微信里长按图片就能保存。
- **进度保存**：闯关进度保存在手机浏览器里，下次打开可以「继续上次的旅程」。每站都能重玩刷星，只保留最好成绩。

## 改内容

**所有文字、站点、小游戏参数、题库和称号都在 `flow.yaml` 里**，改这个文件就行，不用动代码。

- 加题目：在 `quiz_game.questions` 里照格式加一项，`correct_index` 从 0 开始数。选项顺序游戏里会自动打乱。
- 调难度：
  - 打妖怪：改 `duration`（秒数）和 `stars`（各星级需要的分数）
  - 漕船：改 `distance`（航程）、`lives`（生命数）和 `stars`（粮袋数）
- 改时间线：改 `events`，按正确顺序填写，游戏里会自动打乱。
- 改称号：改 `endscreen.ranks`，`min` 是 0 到 1 之间的得分率。
- 站点在地图上的位置：改 `position` 的 x / y（百分比）。
- 加讲解录音：在站点里加一行 `audio: "assets/audio/xxx.mp3"`。不加的话，会用手机自带的中文语音朗读。

## 本地运行

`flow.yaml` 是用 `fetch()` 读取的，所以要起一个本地服务器，不能直接双击打开 `index.html`：

```bash
cd huaian-game
python3 -m http.server 8080
# 手机和电脑连同一个 Wi-Fi，打开 http://电脑IP:8080
```

## 部署

全部是静态文件，不需要构建：

- **Vercel**（本仓库已在用）：部署后访问 `https://你的域名/huaian-game/`，扫码页是 `/huaian-game/qr.html`。
- **GitHub Pages / 任意静态托管**：把 `huaian-game` 文件夹上传即可。

所有依赖（js-yaml、二维码生成库）都放在 `js/vendor/` 里，不依赖境外 CDN，国内网络也能正常打开。

## 图片和音效

图片都是用代码画的扁平风插画，音效和背景音乐是用代码合成的五声音阶拨弦声，可以自由使用和修改。

```bash
python3 art/make_art.py                    # 生成 art/svg/*.svg
node art/render.mjs                        # 渲染成 assets/ 里的 jpg / png（需要 playwright）
python3 art/make_audio.py                  # 合成 assets/audio/*.mp3（需要 numpy、ffmpeg）
```

小游戏里的短音效（打中、收集、撞船、盖章等）是用 Web Audio 在浏览器里实时合成的，不需要音频文件。

想换成真实照片的话，直接替换 `assets/images/` 里的同名文件就行。展区图片建议用 5:4 的比例。

## 目录结构

```text
huaian-game/
├── index.html          # 游戏主页面
├── qr.html             # 扫码展示页（大屏 / 展板用）
├── flow.yaml           # 全部内容配置
├── css/                # 样式
├── js/
│   ├── app.js          # 页面流程：地图、站点、进度保存、结算
│   ├── game.js         # 限时答题、徽章动画
│   ├── games/          # 四个小游戏：timeline / whack / canal / tangbao
│   ├── poster.js       # 分享海报
│   ├── sfx.js          # 音效
│   └── vendor/         # js-yaml、qrcode-generator（MIT 许可）
├── assets/             # 图片、图标、音效
└── art/                # 生成图片和音效的脚本
```
